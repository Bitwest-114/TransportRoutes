# Пошук транспортних маршрутів

 проєкт із двох частин: вебзастосунку `Transport.Web` та API `Transport.Service`.

## Запуск у Visual Studio

1. Відкрийте `TransportRoutes.slnx`.
2. Натисніть **F5** — запустяться обидва проєкти.
3. Вебсторінка відкривається за адресою `http://localhost:5102`.

API працює на `http://localhost:5101`. Приклад пошуку: `/api/routes?departure=Івано-Франківськ&destination=Київ`.
